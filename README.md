# TinySteps — Kids Shoes Store

A complete React + Vite demo storefront for a kids footwear brand.

## Run locally

1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite (normally http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## What's included

- Responsive home page
- Product catalogue with 12 demo shoes
- Search
- Category / age / price filters
- Sorting
- Product details and size selection
- Wishlist
- Cart with quantity controls
- Checkout demo
- Size guide
- localStorage cart + wishlist persistence
- Mobile responsive navigation
- Demo product images sourced from Unsplash

## Important

This is a frontend demo. Checkout, payments, authentication, inventory and order processing are not connected to a backend yet.

Replace the demo product data and image URLs in `src/main.jsx` when you are ready to add your actual catalogue.
